# \# 🍕 Pizza Store Dashboard

# 

# An interactive \*\*Pizza Store Dashboard\*\* built to analyze sales performance, customer orders, product trends, and revenue insights.

# 

# \## 📊 Project Overview

# 

# The Pizza Store Dashboard provides a clear view of key business metrics and helps understand how the pizza store is performing across different products, categories, and time periods.

# 

# The dashboard focuses on transforming raw sales data into meaningful and interactive business insights.

# 

# \## 🎯 Objectives

# 

# \* Analyze overall pizza sales performance

# \* Track total revenue and orders

# \* Identify best-selling pizzas

# \* Analyze sales by pizza category

# \* Understand daily and monthly sales trends

# \* Analyze customer ordering patterns

# \* Identify top-performing products

# \* Support data-driven business decisions

# \## 📐 DAX Measures

# 

# Example measures used in the dashboard include:

# 

# ```DAX

# Total Revenue = SUM(pizza\_sales\[total\_price])

# ```

# 

# ```DAX

# Total Orders = DISTINCTCOUNT(pizza\_sales\[order\_id])

# ```

# 

# ```DAX

# Total Pizzas Sold = SUM(pizza\_sales\[quantity])

# ```

# 

# ```DAX

# Average Order Value =

# DIVIDE(\[Total Revenue], \[Total Orders])

# ```
